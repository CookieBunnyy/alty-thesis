# Abellar Realty Desktop Frontend

This project implements the internal desktop application shell for Abellar Realty.

## Included in this phase

- Application entry point
- Login screen
- Main window shell
- Sidebar navigation
- Top header
- User profile area
- Notification area
- QStackedWidget-based page navigation
- Role-aware session state
- Placeholder pages for all initial major modules
- API client foundation and session management

## Run

```powershell
cd "D:\Alty Thesis System\desktop-side\frontend"
python -m pip install -r requirements.txt
python main.py
```

## Notes

- This is the internal management desktop shell only.
- The public website is intentionally not included.
- Placeholder pages are meant to be replaced with concrete module implementations when the backend endpoints become available.
